# Static-Site-Generator learning goals:

- Design clean, modular code using classes, inheritance, and encapsulation to represent nodes in a document tree.
- Parse Markdown into abstract syntax trees, transforming nested block and inline elements into structured HTML.
- Use Python's standard library to crawl directories, manipulate paths, copy assets, and write out generated files.
- Extract patterns from raw text, such as Markdown links, images, headers, and formatted blocks.
- Understand how static site generators assemble pre-rendered HTML and CSS from content and templates, and why this model is used for performance and security.
- Write unit tests to verify transformations and deploy the final generated site to a live URL.
